### Added

- Changelog fragments: each PR adds `changelog.d/<issue>.md` instead of editing `CHANGELOG.md`, and
  `rake changelog:compile[version]` folds them into a release section (`changelog:check` and
  `changelog:preview` too). New ADRs are named after their issue number, and `rake adr:index`
  rewrites the ADR index at release (`rake release:prepare` runs both). CI runs
  `rake changelog:check adr:check` and also triggers on `merge_group`. ADR 0072 (#72).

### Changed

- The Definition of Done in the issue and PR templates, `CLAUDE.md`, `CONTRIBUTING.md` and
  `/work-issue` now ask for a changelog fragment instead of a `CHANGELOG.md` line (#72).
