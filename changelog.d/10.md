### Added

- The processed cache tier, `SportsIngest::Cache::Processed`: saves a collection of one model
  class under a key with its source, `fetched_at`, model class and schema version, and reads it
  back as a `Processed::Entry`. Reads miss when the model class or its `SCHEMA_VERSION` changed,
  the entry is older than `max_age:`, or it's damaged; writes raise if the collection wouldn't
  read back unchanged. Disk entries live under `<cache_dir>/processed`. ADR 0010 (M1-07).
- `Configuration#processed_cache` (`SPORTS_INGEST_PROCESSED_CACHE`): `disk` (default), `memory` or
  `off` (M1-07).
- `Cache.store_for(mode, tier:)`, shared by both tiers; `Cache::Raw.store_for` now calls it (M1-07).

### Fixed

- `Cache::DiskStore` reads entries as UTF-8 whatever the locale, so non-ASCII text (player names,
  response bodies) no longer reads as a miss when `LANG` is unset, as under cron (M1-07).
