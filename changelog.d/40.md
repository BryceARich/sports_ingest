### Added

- nflverse release downloader: `SportsIngest::Nflverse::ReleaseDownloader#fetch(tag, file)`
  downloads an asset from the `nflverse/nflverse-data` GitHub releases to
  `<cache_dir>/releases/nflverse/<tag>/<file>` and returns a `ReleaseFile` (path, URL,
  `last_updated`, `fetched_at`, `stale`). The file is downloaded once and reused until the tag's
  `timestamp.json` changes; that check goes through the raw cache, so it happens at most once per
  nflverse TTL. When the network fails, the last copy is returned with `stale: true`. ADR 0040 (M5-01).
