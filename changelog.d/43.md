### Added

- nflverse player ID map: `SportsIngest::Nflverse::IdMap#gsis_id(source:, id:)` maps an ESPN or
  PFR player ID to nflverse's GSIS ID, from the `players` release. An ID shared by two
  GSIS IDs returns `nil` rather than a guess. `IdMap#players` lists each player's IDs as
  `Nflverse::PlayerId` models, and the table is saved to the processed cache. ADR 0043 (M5-04).
