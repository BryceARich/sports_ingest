### Added

- NHL player details: `SportsIngest::NHL.player(id)` / `NHL::Players#fetch` return an
  `NHL::PlayerDetails` with the player's bio as the same `NHL::Player` rosters give (birth date,
  shoots/catches, current team), whether they're active, their `NHL::Draft`, career regular-season
  and playoff totals and season-by-season totals in every league, as `NHL::StatLine`s (skater and
  goalie stats in one model, times on ice in seconds). ADR 0023 (M2-08).
- NHL game logs: `SportsIngest::NHL.game_log(id, season: 2025, game_type: :playoffs)` /
  `NHL::Players#game_log` return `NHL::GameLogEntry` models, oldest game first; with no season it
  reads the NHL's current log. Details and logs are saved to the processed cache (M2-08).
