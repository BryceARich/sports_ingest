### Added

- nflverse players: `SportsIngest::Nflverse::Players#fetch` reads `players.csv` and returns a
  `Nflverse::Player` for each row with a `gsis_id`, keyed by the `gsis_id` as its canonical ID
  (`Identity::PlayerRef`, football). Rows without a `gsis_id` are skipped. Written to the processed
  cache under `nflverse/players` (M5-03).
- nflverse rosters: `SportsIngest::Nflverse::Rosters#fetch(season)` reads `roster_<season>.csv` from
  the `rosters` release and returns a `Nflverse::RosterEntry` (team, position, jersey number,
  status, full name) for each row with a `gsis_id`. Written to the processed cache under
  `nflverse/rosters/<season>` (M5-03).
