### Added

- `script/claude/run <command>` runs a command with the `.ruby-version` Ruby and a UTF-8 locale,
  for shells without mise activated, such as Claude sessions (#99).
- `docs/SETUP.md`: fresh-machine setup, commands and the file map, moved out of `docs/RESUME.md` (#99).

### Changed

- Specs, rake tasks and `script/claude/*` read files as UTF-8 whatever the shell's locale (#99).
- `docs/RESUME.md` is brought up to date and keeps only status, next issues and gotchas; the
  Claude bot-account setup moves from `CLAUDE.md` to `CONTRIBUTING.md` (#99).
- `rake adr:check` prints one line on success instead of every pending ADR (#99).
- `/work-issue` and `/spawn-unblocked` use `script/claude/run` and add token-saving guidance (#99).
