### Added

- NHL rosters: `SportsIngest::NHL::Rosters#fetch("EDM", season: 2025)` returns
  `SportsIngest::NHL::Player` models (NHL ID as the canonical `PlayerRef`, position, birth date
  and bio) and saves them to the processed cache. Also adds the shared `SportsIngest::NHL::Client`
  for the web API and `SportsIngest::NHL::Season` to convert `2025` to `"20252026"`. ADR 0022 (M2-07).
